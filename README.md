# freo2

freo（フレオ）は、PHPで作成されたコンテンツ管理システムです。
独自の軽量PHPフレームワーク [levis](https://refirio.org/levis/) の上に作られています。

- 公式サイト: https://freo.jp/freo2/

> **開発中のバージョンです。** freo2は現在アルファ版で、機能や画面は今後変わることがあります。

## 特徴

- **記事とページを同じ仕組みで管理できます。** カテゴリー・公開範囲・公開期間などの設定は、記事にもページにも同じように使えます。
- **入力項目を画面から増やせます。** 「価格」「開催日」「資料のPDF」のような項目を、プログラムを書かずに追加できます。
- **テーマとプラグインで拡張できます。** 本体に手を加えずに、見た目の変更や機能の追加ができます。

## 動作環境

- PHP 8 以上
- MySQL 8 以上、または MariaDB 10 以上
- (任意)Apache の mod_rewrite: 有効ならURLから `index.php` を省略できます

## 設置方法

公式サイトの [設置方法](https://freo.jp/freo2/setup/) を参照してください。
開発環境の作り方、テーマとプラグインの作り方も公式サイトにあります。

## プラグイン

すぐに使えるプラグインは、別のリポジトリで提供しています。
ギャラリー、商品・注文管理、マークダウンでの本文入力、URLのリライトなどがあります。

- freo2-plugins: https://github.com/refirio/freo2-plugins
